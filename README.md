# Cyber Saksham — Public Cyber Safety Awareness Website

A responsive, front-end-only public awareness website prototype for a local police station in Karnataka.

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step, backend, database, API key or paid service is required.

## Included
- Responsive landing page and mobile navigation
- Cybercrime awareness cards with detail dialogs
- Interactive personal safety checklist and progress indicator
- Five-question cyber awareness quiz with scoring and explanations
- Official reporting guidance and click-to-call links for 1930 and 112
- Links to the National Cyber Crime Reporting Portal
- Basic language switch for the hero section (English, Hindi, Kannada)

## Important before public deployment
- This is an independent prototype, not an official police/government website.
- Obtain written approval before using a police station name, emblem, seal, official photographs or contact details.
- Replace placeholder branding and have all local contact information reviewed by the police station.
- Have Kannada and Hindi translations professionally reviewed before publication. The current language switch translates the hero copy only.
- Keep the official reporting process linked to `https://cybercrime.gov.in/`. This site does not accept or store complaints.
- Do not add a public form that collects OTPs, passwords, bank details, Aadhaar details or sensitive evidence.
- Review all content with the police station's authorised point of contact before launch.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — interactive cards, checklist, quiz and language selector
